# Plant Disease Diagnosis System using MLOps and Active Learning

## Overview
Developed a machine learning-based plant disease diagnosis system concept using MLOps and active learning. Awarded **3rd Winner at INNOVEST 2026 "Clash of Champions"**.

## Problem
Early detection of plant diseases is crucial for crop yield, but traditional diagnosis methods require expert knowledge and are time-consuming.

## Method
- Image classification with deep learning
- Active learning to efficiently label new data
- MLOps pipeline for continuous model improvement
- Integration with farming workflow

## Result
Awarded 3rd Winner at INNOVEST 2026 "Clash of Champions". System demonstrates effective plant disease classification with efficient data labeling.

## Tech Stack
- Python
- TensorFlow/PyTorch
- Scikit-learn
- MLOps tools (MLflow, Docker, etc.)
- Active Learning frameworks
