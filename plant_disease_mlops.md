# Plant Disease Diagnosis System using MLOps and Active Learning

## Overview

This project proposes a machine learning-based plant disease diagnosis system supported by **Machine Learning Operations (MLOps)** and **Active Learning**.

The main idea is to build a diagnosis workflow where model predictions can be continuously improved through human review, data labeling, and iterative model updates.

## Problem

Plant disease identification can be challenging when farmers or users do not have direct access to agricultural experts. A machine learning-based system can help provide early diagnosis support, especially when combined with a workflow that allows continuous improvement from new data.

However, in real-world conditions, model performance depends heavily on the quality and diversity of labeled data. This project addresses that challenge by combining MLOps and active learning.

---

## Proposed Solution

The proposed system uses an iterative machine learning workflow:

1. Users provide plant images for diagnosis.
2. The model predicts possible disease categories.
3. Low-confidence or uncertain predictions are selected for review.
4. Reviewed samples are added back into the labeled dataset.
5. The model can be retrained and improved over time.

This approach allows the system to continuously improve as more reviewed and labeled data become available.
