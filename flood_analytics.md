# Predictive Flood Analytics with Hadoop Ecosystem in Lampung

## Overview
Built a big data analytics workflow using the Hadoop ecosystem to support flood-related predictive analytics in Lampung.

## Problem
Flooding in Lampung causes significant damage and disruption. Accurate prediction and early warning systems are needed to mitigate impact.

## Method
- Data ingestion with Apache Flume
- Data processing with Apache Spark
- Storage with HDFS
- Machine learning for flood prediction
- Visualization with dashboard tools

## Result
Developed a big data pipeline capable of processing flood-related data and generating predictive insights for Lampung region.

## Tech Stack
- Python
- Hadoop Ecosystem
- Apache Spark
- Apache Flume
- HDFS
- Big Data analytics tools
