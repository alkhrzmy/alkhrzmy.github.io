# End-to-End Spoken Language Understanding for Retail Transaction Recording

## Overview
Developed an Indonesian spoken language understanding pipeline for retail transaction recording using deep learning and MLOps concepts. The project includes data preprocessing, model training, evaluation, and documentation.

## Problem
Recording retail transactions manually is time-consuming and prone to errors. Automating this process through voice input can improve efficiency and accuracy.

## Method
- Speech recognition for Indonesian language
- Named Entity Recognition (NER) for transaction details
- Intent classification for transaction types
- End-to-end pipeline with MLOps best practices

## Result
Built a complete SLU pipeline capable of understanding Indonesian speech and extracting relevant transaction information.

## Tech Stack
- Python
- PyTorch
- Speech Recognition
- Transformers
- MLOps tools
