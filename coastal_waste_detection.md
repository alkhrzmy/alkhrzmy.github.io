# Zero-Shot Coastal Waste Detection and Material Classification

## Overview
Built a zero-shot AI pipeline using Grounding DINO and CLIP to detect and classify coastal waste materials. This project focuses on prompt evaluation, model quality analysis, detection errors, and classification performance.

## Problem
Coastal waste detection is challenging due to the diversity of waste materials and the difficulty in obtaining labeled training data for each material type.

## Method
- **Grounding DINO**: Zero-shot object detection model
- **CLIP**: Contrastive Language-Image Pretraining for classification
- Prompt engineering for different waste categories
- Evaluation metrics: precision, recall, mAP

## Result
Achieved effective detection and classification of various coastal waste materials without requiring task-specific training data.

## Tech Stack
- Python
- PyTorch
- Grounding DINO
- CLIP
- OpenCV
