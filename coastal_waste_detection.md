# Zero-Shot Coastal Waste Detection and Material Classification

## Overview

This project explores the use of **zero-shot vision-language models** for detecting and classifying coastal waste materials in beach environments.

The system combines object detection and image-based material classification to support environmental monitoring and coastal waste analysis.

## General Focus

The project focuses on:

* Coastal waste detection from beach images
* Material classification of detected waste objects
* Prompt-based model evaluation
* Error analysis for false positives and false negatives
* Model quality assessment in a zero-shot setting

---

## Methods Used

* Grounding DINO
* CLIP
* Zero-shot object detection
* Vision-language model evaluation
* Image annotation and validation
* Detection and classification error analysis

---

## Key Learning

Through this project, I learned how to evaluate AI model performance in a real-world environmental dataset, analyze detection errors, and assess the limitations of zero-shot vision-language models for practical computer vision tasks.
